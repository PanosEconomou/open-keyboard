# Switches and Keycaps

I've left the best for last. People spend an enormous amount of time fiddling with these. So far the design allows for a wide variety of keycaps and switches. The only requirements are the MX-compatible footprints for the switchs. So let's find some. [This reddit thread](https://www.reddit.com/r/MechanicalKeyboards/comments/dzamyl/40s_keycaps_where_to_begin/) has some cool starting points. 

A nice keycap type is called PBS and its creator has a [blog post](https://kbd.news/Designing-Keycaps-for-Fun-and-Profit-1775.html) that explains how to make them. It is using an open source python based cad library called [cadquery](https://github.com/CadQuery/cadquery) and another open source keycap library called [OPK](https://github.com/cubiq/OPK).
